# assets/video/

Drop Runway clips here. Each file is optional — the site falls back to its canvas
animation when a file is absent, so you can add them one at a time.

See `docs/VIDEO-SCRIPTS.md` for the prompts, the ffmpeg encoding commands, and the
size budget.

Filenames (each as both `.mp4` and `.webm`). All nine slots are filled.

| File | Slot | What the clip shows |
|---|---|---|
| `hero` | Homepage hero | 3D node lattice, teal with violet accents, light plane sweeping across |
| `pbsd` | ParanoidBSD | Hexagonal armour plates, amber edges, one opening to a teal core |
| `cypha` | Cypha + Cypha Chess | Particle cloud resolving into three clusters — teal, violet, amber |
| `retdec` | RetDec Imortek | Blue-white noise streaks resolving into ordered crystalline structure |
| `mathscript` | MathScript | Violet wireframe manifold undulating |
| `aegis` | AEGIS | Traceable teal pulses, then a violet wash flattening them out |
| `sentinel` | SENTINEL | Topographic contours with teal and amber heat blooms |
| `cellai` | Cell AI | Reaction-diffusion coral growing — the same dynamics as the live demo |
| `kickstarter` | Kickstarter | Amber lattice assembling, deliberately left unfinished |

`cypha` serves two pages: the Cypha product page and the chess demo.

Poster frames go in `assets/img/video/<name>.jpg`.

**Budget: under 4 MB per file, under 25 MB for this directory.**
GitHub hard-blocks any single file over 100 MB.

Current: largest file 1.3 MB, directory 12 MB. Sources were Runway exports at
1280x720 (one at 1926x1076, downscaled; one at 864x496, left at native rather
than upscaled), re-encoded with the commands in `docs/VIDEO-SCRIPTS.md` —
H.264 CRF 30 and VP9 CRF 38, 24fps, audio stripped, `+faststart`.

`manifest.json` is generated by `./tools/build.sh` from the `.mp4` files present
here. Run the build after adding or removing a clip, or the site will not see it.
