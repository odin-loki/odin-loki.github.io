ParanoidBSD

A hardened BSD, rewritten in C++23, with a capability and handle nucleus sitting on top of what HardenedBSD already ships — and KDE Plasma 6 on the desk.

Memory-unsafe C is the substrate almost every operating system still runs on. PBSD takes HardenedBSD 15-STABLE as a behavioural specification and ports it, file by file, to C++23 modules — then adds a security nucleus where every resource is reached through an unforgeable handle rather than an ambient global namespace.

  • Ported faithfully, not “improved”. The HardenedBSD tree is the spec. Bugs are ported too, until a change is logged separately.
  • Nothing is done until it is verified. Compile-only is unverified. Differential or IR verification gates every file.
  • Deterministic tooling first. Safe rewrite passes run before any model touches code — and the model never self-certifies.
  • Freestanding kernel C++. -fno-exceptions -fno-rtti, with a documented kernel ABI.

How this work is done

The standard, stated plainly

Independent software has a credibility problem, and it is usually earned. These are the rules the repositories are actually held to — you can check every one of them against the source.

01

Compile-only is not done

In PBSD, no ported file counts as finished until differential or IR verification passes. In MathScript, correctness is 816 CTest suites against committed goldens. In Cypha, parity with fixture goldens — not a leaderboard number — is the proof.

02

Models fill gaps; they never certify

AI is used where it earns its place — porting refused files, refining decompiler output — and it is always downstream of deterministic tooling and upstream of a hard gate. Compile checks, sanitizers, differential runs and IR comparison decide, not the model.

03

Limitations are published, not buried

Cell AI’s perplexity is orders of magnitude worse than a transformer, and its README says so. AEGIS states that clearnet exit is weaker and that multi-second latency is inherent. RetDec’s name-blind algorithm F1 is 0.056, printed next to the 1.000 name-assisted figure. That is the point.

04

Measurement beats intuition

AEGIS was built to a single rule: nothing is done until an attack simulation confirms it. Intuition about traffic analysis failed repeatedly during development; the simulation harness in sim/ is the evidence ledger behind every quantitative claim in the specification.
